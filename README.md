# シンナー配合計算

気温・天気・クリヤーの種類(GL / QD / SG / グリフィス)を入れると、シンナーの番手(ウルトラ / スーパー / スロー)の配合と量を出す計算ツールです。

## 使い方

1. 「塗装記録を追加」で、これまでに塗った条件(気温・天気・クリヤー・番手の配合・割合)と仕上がりをダイヤルで選んで保存します。
2. 上の入力で気温・天気・クリヤーを選ぶと、記録をもとに、おすすめの配合が出ます。記録は1件から使えます。

## 記録の保存について

- 記録は、使っている端末のブラウザの中だけに保存されます。サーバーには送られません。
- 別の端末には引き継がれません。ブラウザのデータを消したり、Safari でしばらく使わなかったりすると消えることがあります。
- ページ下の「バックアップ」で、記録をファイルに保存し、あとで読み込んで戻せます。
